## 4. 当前计划与阻断条件

- [x] 支持 300 图的上传/契约/数据库约束和 `gpu-large-300` 执行档。

- [x] 功能提交推送、Web 构建、源码 bundle/ZIP 和校验记录；离线 bundle 恢复通过。
- [ ] 目标机实际空闲磁盘 ≥139 GiB、总显存 ≥14 GiB、空闲显存 ≥12 GiB，队列与租约空闲。
- [ ] 停止服务后轮换发布、应用预设并重新生成服务包；检查配置与构建身份。
- [ ] 单次网页 300 图任务、连续阶段/资源证据、三分支结果、评估、租约释放和大 GLB 验收。

## 5. 公网路线（暂缓）

恢复公网路线前仍需：

- 合规入口、真实域名/DNS/TLS、production 实机部署和生产邮件投递；
- 验证码、管理员 UI/二次验证、边缘连接与流量防护；
- 任务预留/超时与传输限额实测校准、并发/SSE/大下载压力测试；
- 集中监控告警、备份恢复、保留策略周期观察与显式清理验收；
- 隐私说明、第三方来源与许可复核。

历史主机预检的某一项 blocker 不代表当前只差该项即可公开发布。受限部署与公网部署按独立条件验收。
