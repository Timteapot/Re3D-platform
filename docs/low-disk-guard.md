# 运行期低磁盘自动取消

## 作用与配置

`DiskGuard` 对 `RE3D_DATA_ROOT` 所在卷执行独立的轻量空闲量检查，不扫描
目录，也不依赖资源样本、NVIDIA 查询或 GPU。标准环境默认关闭；当前受限
实验档 `gpu-experiment-300-20` 强制开启。

```dotenv
RE3D_LOW_DISK_GUARD_ENABLED=true
RE3D_LOW_DISK_GUARD_INTERVAL_SECONDS=1
RE3D_MIN_FREE_DISK_BYTES=21474836480
```

启用时阈值至少为 1 GiB，间隔允许 1–5 秒；受限预设为 20 GiB / 1 秒。
就绪报告的 `disk_guard` 返回启用状态、阈值、周期和探测失败策略，不含秘密。

## 执行与终态

- 启动同步检查，运行期间由独立线程周期探测，触发状态保持至任务结束。
- 空闲量小于或等于安全线时，使用 `LOW_DISK_AUTO_CANCELLED`；读取失败或
  无法可靠监督时，使用 `DISK_GUARD_PROBE_FAILED`，不输出异常正文或私密路径。
- 子进程监督和输出处理检查保护信号并终止受控进程树；结果复用、产物收集、
  评估前后、资源采样退出和成功提交前均设健康检查边界。
- 任务写为 `cancelled`，数据库和 `job_cancelled` 事件保存专用原因码；
  不伪造用户操作审计。终态更新仍须持有有效原租约，租约丢失不能越权写入。
- 用户取消和租约丢失保持原有语义；保护与普通非致命资源采样相互独立。

## 限制与取证

该机制不是磁盘硬配额。20 GiB 为触发阈值，检测、调度和进程终止之间仍存在
延迟；文件复制或哈希中的取消在健康检查边界处理，不能保证剩余字节绝不跌破
阈值。64 GiB 任务预留仍用于准入和记账，不会预分配文件或形成硬封顶。

保护只检查数据根所在卷，不保护另一个系统盘或第三方工具写到的其他卷。
当前实验保持离线模型、受控 TEMP/工作路径、队列空闲和单 GPU 执行。
单用户最多一个非终态任务不等于全平台单任务，实验前还须核对其他活动上传。

失败/取消任务沿用宽限期后的目录清理。若发生自动取消，应立即归档请求、
事件、资源样本、日志和空间摘要至受保护的任务外位置，再转移到本机；不将
原始日志或秘密加入 Git。保护不自动删除任何成功任务，也不改变 30 天 dry-run。
