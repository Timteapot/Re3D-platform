# 三分支 GLB 在线查看器

## 当前作用

任务详情页在成功结果生成后提供 A-v4、B-v2、C 三个分支的交互预览。查看器解决的是“浏览器内检查重建结果”，不会替代原始产物下载，也不会改变自动评估结论。

Three.js 代码使用 React `lazy` 按需加载。主页、说明页、认证页和普通工作台不加载查看器代码；只有具有结果的任务详情会加载它。实际分包大小以对应提交的构建报告为准。

## 数据与鉴权流程

```text
任务详情 result 摘要
  → 只选择具有 download_url 的 GLB
  → 当前 access token 发起认证 Fetch
  → API 复核任务所有者、终态、契约、路径、大小和 SHA-256
  → 浏览器得到 Blob 并创建短期 blob: URL
  → GLTFLoader 解析模型
  → 立即撤销 blob: URL
```

access token 仍只保存在 React 内存中，不写入查询参数、`blob:` URL、浏览器历史或 GLB 文件。服务端物理路径和产物哈希也不会进入页面状态。

## 交互和生命周期

- 默认选择结果清单中的第一个可预览分支，并保持 A-v4、B-v2、C 的服务端顺序；
- 左键旋转、滚轮缩放、右键平移，并可恢复自动计算的初始视角；
- 按包围盒把模型平移到视图中心，根据视野角、宽高比和模型半径计算相机距离；
- 默认绕 X 轴旋转 180°，将 Re3D 的 COLMAP/OpenCV 方向约定转换为 Three.js 的 Y 向上显示；X/Y/Z 角度控件只改变浏览器显示，不改写模型文件；
- 根据面积加权面法向估计初始观察方向；闭合或方向不明显的模型回退到固定斜视角。这是显示启发式，不是建筑正面识别；
- 摄影纹理使用双面、非金属的显示处理；带纹理的标准材质转为不受场景光照影响的预览材质，避免重建法向或 glTF 默认金属参数造成内外亮度误导；
- 浏览器尺寸变化时同步画布和相机投影；像素比最大限制为 2，避免高 DPI 屏幕无界增加 GPU 压力；
- 预览可用性从无变为有时初始化 WebGL 画布；任务终态详情查询取得产物后无需刷新页面即可开始加载；
- 切换分支时取消仍在进行的认证下载，释放旧模型的 geometry、material 和 texture；
- 离开页面时停止渲染循环并释放 controls、网格和 WebGL 上下文。

模拟 Worker 的最小 GLB 是合法空场景。查看器会明确显示“没有可渲染网格”，不会把空场景误报为加载失败或真实重建结果。损坏文件、鉴权错误和 WebGL 不可用也各自显示稳定提示，下载按钮仍可独立使用。

## 当前边界

- GLB 通过完整 Blob 加载，峰值内存会高于文件大小；11 图产物已通过预览验收，扩大规模仍需要浏览器内存实测，不能按图片数量推算模型体积或浏览器上限；
- 暂未实现渐进式网格、LOD、模型测量、裁剪、背景切换或截图；
- 查看器已使用各环境均注册的稳定 `/api/v1/jobs` 产物路由，并受普通 API 来源 IP 请求频率、单用户下载并发/累计字节和存储配额限制；传输限额与任务预留值校准、边缘流量防护和部署加固未完成前仍不能据此开放互联网；
- 自动评估使用 Worker 生成的版本化指标，查看器统计只用于确认浏览器实际解析到的网格数量，不反向修改评分。
