## 验收中发现并修正的问题

1. 提升权限环境中的 Git safe-directory 配置可能不同，导致合法 Re3D 安装被误判。适配器现在只对已配置的 Re3D 根目录显式传入 `safe.directory`，并把操作系统启动错误转换为稳定的完整性错误。
2. Windows 主机与 Docker PostgreSQL 存在亚秒级时钟偏差时，新签发 JWT 可能短暂触发 `ImmatureSignatureError`。解码现在允许最多 5 秒的有界时钟偏差，并有接受 4 秒、拒绝 10 秒的回归测试。
3. 初次 MapAnything 模型加载期间可能长时间没有阶段日志，但进程最终能进入 GPU 推理。验收脚本后续应采集进程、GPU 和磁盘指标，不应使用未经校准的短暂无输出阈值强制终止。
