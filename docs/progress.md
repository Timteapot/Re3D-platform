## 1. 当前阶段

项目处于 **Windows 受限部署验收与容量测试准备阶段**。注册/登录、上传、排队、真实重建、结构评估、模型预览和授权下载已连接成完整链路。服务器已验收的规模为网页 11 图任务；固定管线另已完成 Lighthouse 150 图三分支断点续跑。

网页直接 300 图实验已在 `6e8ad0c` 部署下启动，但未完成三分支重建。已保留部分 SfM 的一致性断点，并完成同源 4/8 线程独立短测；8 线程在该 180 秒窗口约为 4 线程的 2.15 倍速度，这不是全程耗时保证。2026-10-14 已恢复连接并完成独立 8/12 线程短测；收尾四项服务仍为 Stopped/Manual，旧任务和租约未修改，未启动完整长测。

后续路径为独立副本高 CPU 长测：本机已补齐 31 阶段监督器、真实 SfM/Mapper 接线、周期断点、异常取证和短测准入。`2358f9e` 独立工具包通过同源 8/12 线程 CPU 匹配短测，12 线程吞吐约高 22.2%，只认可短窗口准入；32 线程后续阶段、600 秒周期快照实跑和 GPU 阶段仍未验收。完整高配置长测、可恢复环境封装与新服务器恢复验收尚未完成。

为减少服务器在线时间，当前采用本机 CPU 与服务器后续阶段分段验收。2026-10-15 本机 `lighthouse300-local-cpu8-v3` 完成独立 SfM：44,850 对匹配、300/300 图注册、205,329 个稀疏点、平均重投影误差约 1.2143 px；完整门禁、停止证明和最终一致性断点通过。这是从已有 35,786 对断点续跑，不是冷启动计时或几何精度认证。源断点与旧任务/租约未修改，服务器保持停机。

当前将通用 CPU 监督、取证、可恢复断点和 SfM 交接修复与 C-only 临时实验拆分。主线不提供 C-only 执行入口；实验代码仅在 `experiment/local-c-only` 分支独立维护，暂不合入 `main`，不改变网页默认三分支或冻结算法基线。清理回执的 14 个删除目标与必要源/依赖无路径交集；受保护成果内容仍需清理后复核，不能用元数据或历史成功替代执行准入。真实 SfM 导出/导入、C-only 与服务器 A/B 实跑仍待验收。

CPU 交接工具实现验收分三批：核心 113 项通过、1 项平台夹具跳过；最终 CPU/入口/封装 58 项通过；Mapper 实际参数契约及合成导出/导入 3 项通过。批次有重叠，不相加为独立测试总数。默认入口与候选 profile 均仅准备，源码编译和 `git diff --check` 通过。实现验收记录为仓库外 `Re3D-data/acceptance-logs/lighthouse300-hybrid-tools-local-20261014.json`；发布的源码提交、完整门禁、远端身份、归档 SHA 和恢复核验由独立发布清单绑定，不回写该历史实现记录。

## 5. 公网路线（暂缓）

恢复公网路线前仍需：

- 合规入口、真实域名/DNS/TLS、production 实机部署和生产邮件投递；
- 验证码、管理员 UI/二次验证、边缘连接与流量防护；
- 任务预留/超时与传输限额实测校准、并发/SSE/大下载压力测试；
- 集中监控告警、备份恢复、保留策略周期观察与显式清理验收；
- 隐私说明、第三方来源与许可复核。

历史主机预检的某一项 blocker 不代表当前只差该项即可公开发布。受限部署与公网部署按独立条件验收。
